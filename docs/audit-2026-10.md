# SmartChef audit, 2026-10-17

Scope: static review plus automated checks on commit `38ee0b1` (frontend 1.13.0, backend 1.10.2). No code was changed.

**Not done:** interactive feature walk-throughs (UI, Electron, Android, two-device sync) were not run. Feature status below rests on the automated suite and on code review.

## Results of automated checks

| Check | Result |
|---|---|
| Frontend `npm test` | 101 files, 1186 tests, all pass |
| Frontend `tsc --noEmit` | clean |
| MCP `tsc --noEmit` | clean |
| Backend `tsc --noEmit` | **fails**: `src/services/llm.parser.ts(840,5)` TS2353, `regions` not in `LLMParseResult` |
| Frontend `npm audit --omit=dev` | 9 vulns (1 critical `@capacitor/android`, 2 high, 6 moderate) |
| Backend `npm audit --omit=dev` | 7 vulns (1 critical `proxy-addr`, 3 high, 2 moderate, 1 low) |

## Findings

### Critical / High
1. **Plaintext GitHub token in root `.env`.** The file is gitignored and not in history, but should be revoked and rotated if it was ever backed up or shared. Not repeated here.
2. **Backend does not typecheck.** `shared/types/index.ts` `LLMParseResult` has no `regions` field, but `llm.parser.ts:840` returns one. A `tsc` build (the Docker backend build) will fail, so AI import of origin regions cannot ship from a clean build. Fix: add `regions?: Array<{country: string | null; place: string | null}>` to the shared type.
3. **Default secrets with no production guard.** `SESSION_SECRET` (`requireAuth.ts`, `docker-compose.yml:46`) and `LLM_KEY_ENCRYPTION_SECRET` (`docker-compose.yml:72`) fall back to public dev values. Anyone who knows them can forge session cookies. The app never refuses to start in production with these. `.env.example` also documents `JWT_SECRET`, which the code does not read.
4. **Postgres and MCP ports published to the host.** `docker-compose.yml` maps `5432:5432` with default password `smartchef_secret`, and MCP `3002:3002`. Bind to `127.0.0.1` or drop the mappings.
5. **Open API until first account exists** (`requireAuth.ts`). Intended for first-run setup, but a freshly deployed public instance can be claimed by whoever reaches it first.
6. **Dependency advisories**, see table above, including `proxy-addr` IP spoofing (backend, `npm audit fix` available) and `@capacitor/android` (critical, frontend).

### Medium
7. CORS defaults to `*` (`index.ts:48`). With `credentials: true` browsers reject cookies cross-origin, so the setting is both unsafe-looking and non-functional. Set an explicit origin per deployment.
8. No rate limiting on `/api/auth` (login brute force).
9. `COOKIE_SECURE` defaults to `false`.
10. `/health` hardcodes version `1.1.1` (package is 1.10.2).
11. No CI for tests, typecheck or build (only the F-Droid repo workflow). The backend/MCP have no tests, which is how finding 2 went unnoticed.
12. No lint or format tooling in any package.

### Compliance
- **License:** MIT in `LICENSE`. No third-party notices file. Assets needing attribution: Material Symbols, `world-atlas`, OSM tiles and Nominatim (usage policy: identify the app, 1 request/s), Inter/Manrope fonts, avatars. Add `THIRD-PARTY-NOTICES.md`.
- **Privacy:** README claims "no account, no telemetry, no cloud". Outbound calls found: the user's chosen LLM provider, Nominatim and OSM tiles, the git remote, a one-time Tesseract language-model download. These match the claim, but there is no standalone PRIVACY.md and the user is not told that recipe text and ingredient names go to cloud LLM providers. Add one.
- **Android:** `allowBackup="false"`, only `INTERNET` permission. No cleartext or network-security config found.
- **F-Droid:** `fdroid/metadata/com.smartchef.app.yml` is current (builds up to 1.13.0 / versionCode 39, `CurrentVersion` matches) and declares `AntiFeatures: NonFreeNet`. Not verified: that all bundled fonts and assets are FOSS-licensed.
- **Fastlane:** en-US and it-IT only, while the app ships four languages (es, fr missing).
- **Repo hygiene:** `.env*`, `*.jks`, `*.log`, backups and `release-assets/` are ignored and untracked. The logs checked contain only build output or a console error, no personal data. The four `smartchef-backup-*.json` files at the root do contain real library data and stay on disk only.
- **Accessibility:** 35 files use `aria-*`/`role`, but there are no accessibility tests. Not audited visually.
- **i18n:** four locales with a parity test (`locales.test.ts`), passing.

### Features
The 1186 passing tests cover recipes and scaling, import, planner, shopping list, sync merge, locales and the local router. Status per feature in `docs/status.md` is consistent with the code. Anything needing a running UI (cook mode, drag-and-drop planner, print, Android, Electron) is **unverified** by this audit. Known documented gap: legacy CRDT `/api/sync/*` is marked non-functional.

## Recommended order
1. Rotate the GitHub token.
2. Fix the shared `regions` type and run backend `tsc` in CI.
3. Fail startup in production on default secrets; change compose to bind DB/MCP to localhost.
4. `npm audit fix` for backend; review the Capacitor upgrade for frontend.
5. Add rate limiting, PRIVACY.md, THIRD-PARTY-NOTICES.md, a CI workflow (test + tsc for all packages).

## Remediation status (2026-10-20)

Fixed: backend `regions` type, production secret guard, compose secrets required and DB/MCP bound to localhost, backend `npm audit fix` (7 to 3 vulns), auth rate limiting, `/health` version, `.env.example`, CI workflow (`.github/workflows/ci.yml`), `PRIVACY.md`, `SECURITY.md`, `THIRD-PARTY-NOTICES.md`, `license: MIT` in the package.json files.

Left open on purpose:
- **Frontend advisories (9, incl. critical `@capacitor/android`).** `npm audit fix` errors out in this tree (npm "edgesOut" bug); fixing needs a Capacitor upgrade and an Android test pass.
- **CORS `*` default and `COOKIE_SECURE=false`.** Deliberate so plain-HTTP LAN setups work; documented in `SECURITY.md`. Set both per deployment.
- **react-leaflet is Hippocratic-2.1 licensed**, a possible blocker for official F-Droid inclusion (see `THIRD-PARTY-NOTICES.md`).
- **Fastlane has no es/fr listings.**
- **Interactive feature checks (UI, Electron, Android, sync)** were not run.
